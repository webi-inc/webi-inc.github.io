## 1. 프로젝트 개요

부동산 나우는 지역 기반 부동산 매물 정보를 지도 인터페이스로 제공하는 O2O 중개 플랫폼입니다. 사용자는 지도상에서 직관적으로 매물 위치를 확인하고, 상세 정보를 조회할 수 있습니다. 본 프로젝트는 기획 단계부터 개발, 배포까지 전 과정을 수행하여 클라이언트의 비즈니스 요구사항을 완전히 구현했습니다.

## 2. Tech Stack & Spec

* **Role**: 기획, 퍼블리싱, 백엔드 개발
* **CMS**: Gnuboard (Customized)
* **Infrastructure**: LAMP (Linux + Apache + MySQL + PHP)
* **External API**: 네이버 지도 API
* **Status**: 운영 종료

## 3. 핵심 구현 기능

### 네이버 지도 API 연동

네이버 지도 API를 활용하여 매물의 위치 정보를 지도상에 마커로 표시했습니다. 사용자는 지도를 확대/축소하거나 드래그하여 원하는 지역의 매물을 탐색할 수 있으며, 마커 클릭 시 해당 매물의 상세 정보(가격, 면적, 옵션 등)를 팝업 형태로 확인할 수 있습니다.

- 지오코딩을 통한 주소-좌표 변환 처리
- 마커 클러스터링을 통한 대량 매물 표시 최적화
- 지도 이벤트 핸들링 및 비동기 데이터 로드

### 관리자 매물 관리 시스템

그누보드 관리자 페이지를 확장하여 부동산 매물 전용 관리 기능을 구축했습니다. 매물 등록, 수정, 삭제는 물론 이미지 업로드, 옵션 선택, 노출 상태 관리 등 실무에 필요한 기능을 제공합니다.

- CRUD 기반 매물 관리 인터페이스
- 다중 이미지 업로드 및 썸네일 자동 생성
- 매물 상태 관리 (판매중/예약중/거래완료)
- 검색 및 필터링 기능

### 그누보드 커스터마이징

그누보드의 게시판 구조를 확장하여 부동산 매물 특화 데이터베이스 스키마를 설계하고, 매물 유형(아파트, 빌라, 오피스텔 등)별 맞춤형 입력 폼을 구현했습니다. 기본 게시판 기능을 유지하면서도 부동산 도메인에 최적화된 사용자 경험을 제공했습니다.

## 4. Retrospective

본 프로젝트는 CMS 기반 솔루션을 비즈니스 요구사항에 맞게 커스터마이징하는 역량을 축적하는 계기가 되었습니다. 특히 외부 API 연동과 관리자 기능 확장을 통해 그누보드의 확장 가능성을 실무적으로 검증할 수 있었으며, 지도 기반 서비스 개발 경험은 이후 유사 프로젝트에 활용될 수 있는 기술적 자산이 되었습니다.
